== 画面設計
ファイル: docs/chapters/screen_design.adoc

=== メイン画面
実装ファイル：
* MainWindow.xaml/cs - メインウィンドウの定義とコードビハインド
* MainWindow.UI.cs - UI関連の処理
* MainWindow.Base.cs - 基本機能の実装
* MainWindow.Init.cs - 初期化処理
* MainWindow.Controls.cs - コントロールイベントハンドラ

メイン画面は以下の4つの領域で構成されます：

* 設定部 - 通信設定とデリミタ設定
* コマンド実行部 - 単発送受信タブと繰り返し送受信タブ
* 送受信履歴 - ログの表示と操作
* 統計情報 - 各種統計データの表示

[plantuml]
....
salt
{
    {^"設定部"
        {
            {
                通信設定 | "IPアドレス:" | [                 ] | "ポート:" | [    ] | [接続]
            }
            {
                デリミタ設定 | "CR+LF (\r\n) ^"
            }
        }
    }
    {^"コマンド実行部"
        {T
            + 単発送受信
            + 繰り返し送受信
        }
    }
    {^"送受信履歴"
        {#
            タイムスタンプ | 種別 | データ | 結果 | 応答時間
        }
    }
    {^"統計情報"
        {
            接続情報 | 送受信カウンター | 応答時間 | エラーカウンター
        }
    }
}
....

=== コマンド編集画面
実装ファイル：
* Views/CommandEditWindow.xaml/cs - コマンド編集ウィンドウの定義とコードビハインド

コマンドの追加・編集用のモーダルウィンドウです：

* コマンドテキスト入力部 - マルチライン入力、制御文字挿入可能
* 送受信モード選択 - 通常/受信のみ/送信のみから選択
* タイムアウト設定 - ミリ秒単位で指定
* 待ち時間設定 - ミリ秒単位で指定

[plantuml]
....
salt
{
    {^"コマンド設定"
        {
            {
                [コマンドテキスト                             ]
                [                                            ]
                [                                            ]
                [制御記号挿入]
            } |
            {
                "送受信モード" | ["通常モード ^"]
                "タイムアウト(ms)" | [1000      ]
                "待ち時間(ms)" | [0         ]
            }
        }
    }
    {
        [OK] | [キャンセル]
    }
}
....

=== ASCII制御文字選択画面
実装ファイル：
* Views/AsciiControlCharacterWindow.xaml/cs - ASCII制御文字選択ウィンドウの定義とコードビハインド
* Models/AsciiControlCharacter.cs - ASCII制御文字の管理クラス

ASCII制御文字を選択するためのモーダルウィンドウです：

* 制御文字の一覧を表示
* ダブルクリックで選択完了
* [NUL]などの形式で表示

[plantuml]
....
salt
{
    {
        {#
            + [NUL]
            + [SOH]
            + [STX]
            + [ETX]
            + ...
            + [DEL]
        }
    }
}
....

=== 応答時間分布グラフ画面
実装ファイル：
* ResponseTimeDistributionWindow.xaml/cs - 応答時間分布グラフウィンドウの定義とコードビハインド
* Models/CommunicationStatistics.cs - 通信統計データの管理クラス

応答時間の分布をグラフ表示するモーダルウィンドウです：

* 横軸：応答時間（ms）
* 縦軸：頻度
* ヒストグラム形式で表示

[plantuml]
....
salt
{
    {^"応答時間分布"
        {
            {+
                    ^
                    |
                # # |    #
                # # | #  #
                # # | #  # #
                # # | #  # #
                -------------------->
            }
        }
    }
}
....

=== 画面遷移

[plantuml]
....
state "メイン画面" as Main {
    state "単発送受信" as Single
    state "繰り返し送受信" as Sequence
    Single --> Sequence
    Sequence --> Single
}

state "コマンド編集" as Edit
state "制御文字選択" as Ascii
state "応答時間グラフ" as Graph

Main --> Edit : コマンド追加/編集
Main --> Graph : グラフ表示
Edit --> Ascii : 制御文字挿入
Edit --> Main : OK/キャンセル
Ascii --> Edit : 制御文字選択
Graph --> Main : 閉じる
....
