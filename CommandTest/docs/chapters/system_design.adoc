== システム設計

=== 全体構成

アプリケーションは以下の3つの主要コンポーネントで構成されます：

* Models - ビジネスロジックとデータモデル
* Views - 画面のUI定義とコードビハインド
* Communications - 通信機能の実装

[plantuml]
....
package "CommandTest" {
    package "Models" {
        [Command]
        [CommandQueue]
        [CommunicationSettings]
        [CommunicationStatistics]
        [AsciiControlCharacter]
    }

    package "Views" {
        [MainWindow]
        [CommandEditWindow]
        [AsciiControlCharacterWindow]
        [ResponseTimeDistributionWindow]
    }

    package "Communications" {
        interface "ICommunicator"
        [TcpCommunicator]
        [CommandExecutionManager]
    }

    [MainWindow] --> [Command]
    [MainWindow] --> [CommunicationSettings]
    [MainWindow] --> [CommandExecutionManager]
    [CommandEditWindow] --> [Command]
    [AsciiControlCharacterWindow] --> [AsciiControlCharacter]
    [CommandExecutionManager] --> [ICommunicator]
    [TcpCommunicator] ..|> [ICommunicator]
}
....

=== 各コンポーネントの役割

==== Models
* Command - コマンドのデータモデル
* CommandQueue - コマンドの実行キュー
* CommunicationSettings - 通信設定の管理
* CommunicationStatistics - 通信統計の管理
* AsciiControlCharacter - ASCII制御文字の管理（静的クラス）

==== Views
* MainWindow - メインウィンドウのUI/コードビハインド
* CommandEditWindow - コマンド編集画面のUI/コードビハインド
* AsciiControlCharacterWindow - ASCII制御文字選択画面のUI/コードビハインド
* ResponseTimeDistributionWindow - 応答時間グラフ画面のUI/コードビハインド

==== Communications
* ICommunicator - 通信インターフェース
* TcpCommunicator - TCP/IP通信の実装
* CommandExecutionManager - コマンド実行の管理

=== データの流れ

[plantuml]
....
actor User
participant "MainWindow" as Main
participant "CommandEditWindow" as Edit
participant "AsciiControlCharacterWindow" as ASCII
participant "CommandExecutionManager" as Exec
participant "TcpCommunicator" as TCP

User -> Main : コマンド編集
Main -> Edit : 編集ウィンドウを表示
Edit -> ASCII : 制御文字選択
ASCII --> Edit : 選択結果を返却
Edit --> Main : 編集結果を返却
Main -> Exec : コマンド実行
Exec -> TCP : 送信要求
TCP --> Exec : 受信データ
Exec --> Main : 実行結果
Main --> User : 結果表示
....

=== データモデル

[plantuml]
....
class Command {
    +CommandText: string
    +Mode: string
    +Timeout: int
    +Interval: int
    +Clone(): Command
}

class CommandRequest {
    +Command: Command
    +IsSequenceCommand: bool
    +ExecutionStartTime: DateTime
    +ExecutionEndTime: DateTime?
    +ReceivedData: string
}

class LogEntry {
    +Timestamp: DateTime
    +Type: string
    +Data: string
    +Result: string
    +ResponseTime: double
}

class CommunicationSettings {
    +IpAddress: string
    +Port: int
    +Delimiter: string
}

class CommunicationStatistics {
    +ConnectionCount: int
    +SendSuccessCount: int
    +ReceiveSuccessCount: int
    +TimeoutCount: int
    +ErrorCount: int
    +ResponseTimes: List<double>
}
....

=== 通信処理の設計

==== シーケンス送受信の流れ

[plantuml]
....
participant "MainWindow" as Main
participant "CommandQueue" as Queue
participant "CommandExecutionManager" as Exec
participant "TcpCommunicator" as TCP

Main -> Exec : EnqueueCommand()
activate Exec
Exec -> Queue : Enqueue()
Queue -> Queue : OnCommandAvailable
Queue -> Exec : ExecuteNext()
Exec -> TCP : SendAsync()
TCP -> TCP : WaitForResponse()
TCP --> Exec : Response
Exec -> Queue : CompleteCommand()
Queue -> Queue : ProcessNextCommand
deactivate Exec
....
